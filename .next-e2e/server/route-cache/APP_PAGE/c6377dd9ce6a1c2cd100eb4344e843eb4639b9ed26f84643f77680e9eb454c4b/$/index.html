FAQ

Questions

Is this one AI pretending to be a team?

No. Each companion is a separate agent with its own model, instructions, and memory. Their conversations are real messages saved to your project.

Do the companions just look busy?

No. A companion only moves or changes status when real work happens: a task, a review, or a meeting.

Can it work on a project I already have?

Yes. Upload a folder or ZIP, or connect GitHub. The team works on a separate branch, and nothing is merged without you.

Can I use my ChatGPT or Claude subscription?

Chat subscriptions are not API keys, so we connect through official API keys. Where a provider offers an approved way to use a subscription, we will support it and explain what it covers.

What will it cost?

Pricing is not final yet. Early access members hear first, and you will always see the estimated cost of a goal before work starts.
